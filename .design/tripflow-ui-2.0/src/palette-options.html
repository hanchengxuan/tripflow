Palette study

三个更克制的配色方向

三个选项只替换颜色 token —— 结构、间距、字阶、阴影完全不动，所以对比是诚实的：你看到的差异全部来自配色。

  • 现有配色的问题：6 个类型色和主色饱和度在同一档，加上薄荷绿画布和选中态，整个界面被染成一片绿。
  • 三个选项的共同修正：画布和表面改为真中性灰，选中态几乎不带色相，类型色统一降饱和到同一族（同明度、同彩度），主色只出现在唯一的主动作上。
  • 钱的语义保持不变：进项用绿、出项用琥珀/赭，红色只留给错误与删除。三套都通过 WCAG AA。
Option A

Slate & Indigo

冷中性灰 + 单一靛蓝。Linear、Revolut 的路子——最像“成熟软件”，颜色几乎只在主动作和状态上出现。靛蓝与钱的绿/琥珀互不干扰。
